# Guía para Claude

Este repo es el espacio de trabajo de la búsqueda laboral del usuario. Todo lo que se produzca en las sesiones (CVs, cartas, investigación, prep de entrevistas) se guarda acá.

- Escribir en español, salvo que el contenido sea para una postulación en otro idioma.
- Respetar la estructura y convenciones del `README.md`.
- Al trabajar sobre una postulación nueva o un cambio de estado, actualizar `postulaciones.md`.
- Para empresas y entrevistas nuevas, partir de las plantillas en `plantillas/`.
