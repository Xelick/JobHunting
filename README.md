# Job Hunting

Repositorio central para todo lo relacionado con la búsqueda laboral: CVs, cartas de presentación, investigación de empresas, preparación de entrevistas y seguimiento de postulaciones.

## Estructura

| Carpeta / archivo | Contenido |
| --- | --- |
| [`postulaciones.md`](postulaciones.md) | Tracker de todas las postulaciones y su estado |
| [`cv/`](cv/) | Versiones del CV (general y adaptadas por puesto) |
| [`cartas/`](cartas/) | Cartas de presentación |
| [`empresas/`](empresas/) | Investigación de cada empresa (un archivo por empresa) |
| [`entrevistas/`](entrevistas/) | Preparación y notas de entrevistas |
| [`plantillas/`](plantillas/) | Plantillas para empresas y entrevistas |

## Convenciones

- Nombres de archivo en minúsculas y con guiones: `empresas/acme-corp.md`, `cartas/2026-10-acme-corp-backend.md`.
- Archivos fechados empiezan con `AAAA-MM-DD` para que se ordenen solos.
- Cada postulación nueva se agrega como fila en `postulaciones.md`.
